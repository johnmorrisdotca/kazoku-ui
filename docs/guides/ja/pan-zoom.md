[English](../pan-zoom.md)

`@johnmorrisdotca/kazoku-ui/pan-zoom`は、平面に描くビュー（星図、国の地図、トーナメント表など）のためのものです。[表示の操作](view-controls.md)は3Dの物体を回すために作られています（指のドラッグでは傾かず、ズームの範囲は狭く、ふつうのホイールはページが使います）。平面のグラフにはその逆が必要なので、この部品は**ビュー**だけを持ち、変わったらページに知らせます。何も描かず、何も送らず、自前のDOMも持たないので、サーバーでもインポートできます。

```ts no-check
import { createPanZoomController } from "@johnmorrisdotca/kazoku-ui/pan-zoom";

const pz = createPanZoomController({
  minZoom: 0.6,
  maxZoom: 60,
  onChange: ({ x, y, zoom }, reason) => draw(x, y, zoom),
});
const unbind = pz.bind(canvas); // キーを受けるには、canvasにtabindex="0"が必要です
```

## ビュー

ビューは`{ x, y, zoom }`です。`x`と`y`は、内容が要素の中心から右と下へ動いたCSSピクセル数、`zoom`は全体表示で1、2なら内容が2倍の大きさになります。この3つの数を、ページが自分の投影（中心と縮尺、CSSの変形など）に当てはめます。`pz.view`は今のビューで、`onChange(view, reason)`は変更のたびに呼ばれます。`reason`は`"drag"`（ドラッグ）、`"pinch"`（ピンチ）、`"wheel"`（ホイール）、`"key"`（キー）、`"api"`（コードからの呼び出し）のどれかです。

## `bind(element)`がすること

| 操作 | 結果 |
| --- | --- |
| 1本指、ペン、またはマウスの左ボタン | ドラッグで、内容を上下左右どちらへも動かします。 |
| 2本指 | 2本の指の中間点を中心にピンチでズームし、その中間点の動きでパンします。 |
| ホイール | ポインターを中心にズームします（下を参照）。トラックパッドのピンチは、Ctrlを押しながらのホイールとして届きます。 |
| 矢印キー | 要素の短いほうの辺の10分の1だけ、キーの向きに内容を動かします。 |
| `+`と`-`（`=`と`_`も） | 要素の中心を基準に、1.25倍ずつズームします。 |
| `Home` | 最初のビューに戻ります。 |

要素に`touch-action: none`を設定するので、指でドラッグしてもページはスクロールされず、グラフがパンされます。`unbind()`で元の値に戻ります。ドラッグの終わりのクリックも、そのまま届きます。グラフがクリックに反応する場合は、`"drag"`の変更に続くクリックは無視してください。要素にはタブ停止も役割（role）も付きません。ページ側で、グラフが何であるかを伝える名前とあわせて付けてください。

## ふつうのホイール

地図のページでは、ふつうのホイールでズームします。3D部品は、ページがスクロールできるよう、CtrlまたはCommandを押しながらホイールを回したときだけズームします。平面のグラフでは、`wheel`で選べます。

- `"zoom"`（既定）：ふつうのホイールでポインターを中心にズームします。ページやパネルいっぱいのグラフに向いています。
- `"modifier"`：CtrlまたはCommandを押しながらのホイールだけがズームし、ふつうのホイールはページをスクロールします。長いページの途中にあるグラフに向いています。
- `"none"`：ホイールには何もしません。

## 上限・下限と最初のビュー

`minZoom`（既定0.1）と`maxZoom`（既定50）は、表示の操作の上限・下限とは連動しません。そのため、星図なら0.6から60を指定できます。`home`は最初のビューで、`reset()`と`Home`キーはここへ戻ります。`pz.set({ x, y, zoom })`、`pz.panBy(dx, dy)`、`pz.zoomBy(factor, about)`、`pz.reset()`を使うと、自分のボタンからビューを変えられます。ビューが変わらないときは、何も知らせません。計算の部分は、単独でもエクスポートされています。`zoomAbout(view, factor, px, py, min, max)`は、（`px`, `py`）の下にある内容を動かさずにズームします。ほかに`panBy`、`clampZoom`、`wheelFactor`、`distance`があります。

## 含まれないもの

ビューはアドレスには書き込まれません。`?x=&y=&zoom=`が必要なページは、`pz.view`を読んで`pz.set`を自分で呼びます（[アドレスの状態](address-state.md)は、渡したキーを何でも書き込めます）。

## 部品

| インポート | 内容 |
| --- | --- |
| `pan-zoom` | `createPanZoomController`、`zoomAbout`、`panBy`、`clampZoom`、`wheelFactor`、`distance`と、その型。`bind`を呼ぶまでDOMは使いません。 |
