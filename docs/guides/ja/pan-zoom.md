[English](../pan-zoom.md)

`@johnmorrisdotca/kazoku-ui/pan-zoom`は、平面に描くビュー（星図、国の地図、トーナメント表など）のためのものです。[ビューコントロール](view-controls.md)は3Dの物体を回すために作られています（指のドラッグでは傾かず、ズームの範囲は狭く、ふつうのホイールはページが使います）。平面のグラフにはその逆が必要なので、この部品は**ビュー**だけを持ち、変わったらページに知らせます。何も描かず、何も送らず、自前のDOMも持たないので、サーバーでもインポートできます。

```ts no-check
import { createPanZoomController } from "@johnmorrisdotca/kazoku-ui/pan-zoom";

const pz = createPanZoomController({
  minZoom: 0.6,
  maxZoom: 60,
  onChange: ({ x, y, zoom }, reason) => draw(x, y, zoom),
});
const unbind = pz.bind(canvas); // キーを受けるには、canvasにtabindex="0"が必要です
```

## ビュー

ビューは`{ x, y, zoom }`です。`x`と`y`は、内容が要素の中心から右と下へ動いたCSSピクセル数、`zoom`はFitで1、2なら内容が2倍の大きさになります。この3つの数を、ページが自分の投影（中心と縮尺、変換）に当てはめます。`pz.view`が今のビュー、`onChange(view, reason)`が変更のたびに呼ばれ、`reason`は`"drag"`（ドラッグ）、`"pinch"`（ピンチ）、`"wheel"`（ホイール）、`"key"`（キー）、`"api"`（呼び出し）のどれかです。

## `bind(element)`がすること

| 操作 | 結果 |
| --- | --- |
| 指1本、ペン、またはマウスの左ボタン | 内容を縦横どちらへもドラッグします。 |
| 指2本 | 2本の指の中心を軸にピンチでズームし、中心の動きでパンします。 |
| ホイール | ポインタを軸にズームします（下を参照）。トラックパッドのピンチはCtrlを押したホイールとして届きます。 |
| 矢印キー | 要素の短いほうの辺の10分の1だけ、キーの向きに内容を動かします。 |
| `+`と`-`（`=`と`_`も） | 中心を軸に1.25倍ずつズームします。 |
| `Home` | 最初のビューに戻ります。 |

要素に`touch-action: none`を設定するので、指でページがスクロールされず、グラフがパンされます。`unbind()`で元の値に戻ります。ドラッグの終わりのクリックは届きます。グラフがクリックに反応する場合は、`"drag"`の直後のクリックを無視してください。要素にタブ停止位置や役割（role）は付きません。グラフが何かを伝える名前とともに、ページ側で付けてください。

## ふつうのホイール

地図のページではふつうのホイールでズームします。3D部品はページがスクロールできるよう、CtrlまたはCommandを押したときだけズームします。平面のグラフは`wheel`で選びます。

- `"zoom"`（既定）：ふつうのホイールでポインタを軸にズームします。ページやパネルいっぱいのグラフに向いています。
- `"modifier"`：CtrlまたはCommandを押したホイールだけがズームし、ふつうのホイールはページをスクロールします。長いページの途中にあるグラフに向いています。
- `"none"`：ホイールには何もしません。

## 範囲と最初のビュー

`minZoom`（既定0.1）と`maxZoom`（既定50）はビューコントロールの範囲とは別なので、星図なら0.6から60を指定できます。`home`は最初のビューで、`reset()`と`Home`キーはここへ戻ります。`pz.set({ x, y, zoom })`、`pz.panBy(dx, dy)`、`pz.zoomBy(factor, about)`、`pz.reset()`で自分のボタンからビューを変えられ、何も変わらないときは何も知らせません。計算部分も単独で使えます。`zoomAbout(view, factor, px, py, min, max)`は(`px`, `py`)の下にある内容をそのままに保ち、ほかに`panBy`、`clampZoom`、`wheelFactor`、`distance`があります。

## 含まれないもの

ビューはアドレスには書き込まれません。`?x=&y=&zoom=`が必要なページは、`pz.view`を読んで`pz.set`を自分で呼びます（[アドレス状態](address-state.md)の部品は、渡したキーを何でも書けます）。

## 部品

| インポート | 内容 |
| --- | --- |
| `pan-zoom` | `createPanZoomController`、`zoomAbout`、`panBy`、`clampZoom`、`wheelFactor`、`distance`と、その型。`bind`を呼ぶまでDOMは使いません。 |
