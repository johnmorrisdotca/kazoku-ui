Kazoku UI an element that carries the controls

The view controls · Layouts

A package's own element can take the drag, the pinch, the wheel and the keys without a bar. The wheel scrolls the page at Fit; Ctrl or Command and the wheel zooms.

Default: 0.1× to 50×

zoom-min="0.5" zoom-max="4"

controls="none"

With a bar

Limits in code: 1e-6× to 2.5×, with a bar

import { carryControls } from "@johnmorrisdotca/kazoku-ui/view-controls";

connectedCallback() {
  this.controls = carryControls(this, { onChange: (state) => this.draw(state) });
}
disconnectedCallback() {
  this.controls?.unbind();
}
