Kazoku UI a view with its own controller

The view controls · An element that carries the controls

This view makes its own controller and binds it. The page has no bar, the element sends no event and has no controller property. The controller is on window as ownView, and a test hands that name to checkGestures.

const view = createViewController({ turnable: true, onChange: (state) => draw(state) });
view.bind(element);
window.ownView = view; // for a test

await checkGestures(page, "#own", { controller: "ownView" });
