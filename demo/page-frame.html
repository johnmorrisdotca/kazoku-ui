Kazoku UI page header and credits

The view controls

A visitor can land on any page of a demo, from a search, a shared link or a README. Every page therefore says what it is, gives a way home and to the printable sheets, and credits its data, in the top bar and above the footer, with nothing to open.

The header line

The package's name and what this page shows, with Home and, when the package has sheets, a link to them. Home is marked as the current page on the home page. It sits in the page's own top bar, a row of its own, not a second bar.

<kazoku-page-header name="Hoshi Stars" what="The 88 constellations" what-ja="88の星座"
  description="A picture of each of the 88 constellations." sheets="kids.html" meta></kazoku-page-header>

The title and the description

The page's title and description are made from the same words as the header line, so they cannot disagree. A build writes them into the HTML with pageHeadHtml; the header's meta attribute changes them when the reader changes language.
