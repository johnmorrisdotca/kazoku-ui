# Security

This package runs in your page. It makes no network requests, keeps nothing outside the page
except the address when you turn that on, and has no runtime dependencies.

If you find a way to make it do something it should not, please write to john@johnmorris.ca
rather than opening a public issue. Reports are read and kept confidential, and a fix is released
as soon as there is one.

Only the latest version is supported. Browsers: any current one.
